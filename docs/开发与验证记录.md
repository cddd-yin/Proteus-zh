# 开发与验证记录

> 环境：Windows（中文系统）· Proteus 8 Professional **8.16 SP3 (8.16.36097.0)** · Python 3.9（Proteus 自带解释器，纯标准库）

## 时间线（2026-10-06）

1. **可行性调查**
   - 发现 `Translations\`（28 个官方 Qt `.qm`）与 `BIN\LanguagePackInstaller.exe`
   - 二进制字符串证据：`PDS.EXE` 的 `QTranslator / QLocale::system / Proteus translation loaded`；`STARTUP.dll` 的 `Select language pack / Repair language pack / proteus8lang_xxxx.zip`
   - 结论：**官方原生支持语言包，汉化 = 提供 `proteus_zh_CN.qm`，无需修改二进制**
2. **格式逆向**
   - 对照 Qt 4.8.7 / 5.6.3 / 5.7.0 / 6.7 四代 `qtranslator.cpp`，确认 Proteus 使用的 QM 结构四代一致
   - 解析两份真实包：2014「风标」包（6,222 条）与 [picdupe/Proteus-Chinese](https://github.com/picdupe/Proteus-Chinese) 9.x 包（11,070 条）
   - 产出 `工具/qm_reader.py`（解析）与 `工具/qm_writer.py`（编译）
3. **链路验证（全程在安装目录的临时副本上测试，不影响正式安装）**
   - 测试 A：英文基线（截图 `01-英文原版.png`）
   - 测试 B：投放 2014 风包 → 主页部分中文、部分词条因上下文漂移失效（截图 `02-旧汉化包-部分失效.png`）
   - 测试 C：投放「合并词库 + lrelease 编译」包 → 主页 + 555 工程界面全中文
   - 测试 D：投放**纯 Python 编译包**（最终方案）→ 同样全中文（截图 `03`、`04`）
4. **质量治理**
   - 审计发现 picdupe 包在缩写/代号类短词条上有大量机翻噪声（如 `X→十、`、`BM→宝马`、`plane→飞机`、`BOT→机器人`）
   - 加入缩写过滤规则（单/双字符、全大写 2~5 位代号、英文虚词）＋ 定向修正表；共丢弃 329 条
5. **成品构建**
   - 条目数：**16,338**（合并 2014 + picdupe + 本项目修正；冲突 148 处按「2014 优先」）
   - 文件：`成品/proteus_zh_CN.qm`，1,464,807 字节
   - SHA256：`F572FF8E5A4B556FB54BB4AB5F8CDA1E1BCC3820412D73DC45468FE6ABFE1D87`
6. **正式安装（用户授权）**
   - `工具/安装汉化.ps1` 经 UAC 提权安装至正式安装目录，哈希校验一致；原环境无同名文件，无需还原备份
